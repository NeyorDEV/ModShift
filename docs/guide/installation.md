# Installation

ModShift needs **Node.js 20.17+ or 22.13+**.

```bash
# From npm
npm install --global modshift

# From source
git clone https://github.com/NeyorDEV/ModShift.git
cd ModShift
npm ci
npm run build
npm link        # makes the `modshift` command available
```
